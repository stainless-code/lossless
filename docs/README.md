# Lossless docs

[docs site](https://stainless-code.com/lossless/) (install, guides, concepts,
recipes, reference); this folder holds the internals a maintainer needs and a
user does not: forward-looking work and the notes behind it.

**Start here:** [../README.md](../README.md) (repo map), then the file below.

| File                       | Topic                                                |
| -------------------------- | ---------------------------------------------------- |
| [roadmap.md](./roadmap.md) | Forward-looking work, evidence gates, rejected items |

Feature plans, audits, and research notes land here as flat files when an open
roadmap item needs one. None are open, so the folder holds the roadmap only.
