Support every DSH surface. The host composition now runs on a shared core with identity-tied, once-only release, so a stale disposer after a remount cannot evict the replacement; a preset-realm backend entrypoint (`deepseek-lossless/preset`) can mount the compaction engine inside agent presets without mirroring twice or closing shared handles, and it fails fast naming the host row when the core is absent. The new `deepseek-lossless-web` companion bundle ships Lossless variants of all four shipped presets with only the backend row swapped, pinned to the same harness version as the peers. Installing the host bundle switches the host-plane backend with no further edits; web and desktop sessions select a Lossless preset.
