The engine is shared. The peer sets are not.

Pi sessions pick among compaction engines. OpenCode v2 sessions pick among context engines, memory services, or both, so each adapter has its own page. DeepSeek sessions pick between the harness basic backend and this package on one matrix.

## What a cell means

Each cell comes from the peer's source at the commit named in that page's verification note, not from a README. The date on the page covers the peer cells and this package's own. Each page names where a peer leads and which gaps this package keeps.

The audited sources are [comparison/pi.mdx](https://github.com/stainless-code/lossless/blob/feat/deepseek/apps/docs/content/reference/pi/comparison.mdx), [comparison/opencode.mdx](https://github.com/stainless-code/lossless/blob/feat/deepseek/apps/docs/content/reference/opencode/comparison.mdx), and [comparison/deepseek.mdx](https://github.com/stainless-code/lossless/blob/feat/deepseek/apps/docs/content/reference/deepseek/comparison.mdx). The page and the source are the same file.
