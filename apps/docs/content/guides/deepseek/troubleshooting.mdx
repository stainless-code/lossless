Start with `/lcm status`. It reports per-session message and summary counts, the meter window, the resolved swap and re-cut thresholds with a `(clamped)` marker when the clamp pulled a line back, and the last pass outcome. When compactions do not happen, check three things in order: the row is enabled in the profile patch, the base `compaction-basic` row is disabled in the same file, and the profile was restarted after the edit. This recipe covers host-plane profiles (`headless` and custom base profiles); the `web` standard preset mounts its own backend, which this switch does not reach. With the default `enabled: false` the bundle mounts no `/lcm` surface at all, so a missing `/lcm` command means the bundle is still inert; the harness `/compact` path follows whichever compaction service the profile mounts.

When the window gauge disagrees with the harness, compare the thresholds section of `/lcm status` against the routed model window. `thresholdRatio`, `retainRatio`, and `headroomTokens` ride the seam, and the clamp pulls an unusable line back with a `(clamped)` marker.

To file a useful report, run `/lcm diagnose --save <file>`. It builds a redacted bundle without secrets. Include the profile name, the thresholds section from `/lcm status`, and the files list from the [files reference](/reference/deepseek/files). Limits live under [limits](/concepts/limits): what LCM does not do.
