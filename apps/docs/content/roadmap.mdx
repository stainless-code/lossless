Shipped behavior lives in the [guides](/guides/pi/getting-started) and [concepts](/concepts). This page is the forward-looking list. Pull requests welcome. Open an issue first for anything below so we can agree on shape.

This page is adapter-neutral. The [Pi](/reference/pi/tools) and [OpenCode v2](/reference/opencode/tools) reference pages list the host surfaces.

## Next

- **Evidence for summary quality.** The procedural harness already checks that every needle survives many passes and stays readable by address. Its summarizer is mechanical and its needles are literal, so it measures retrieval, not summary quality. A paraphrase-based needle is the next generator, and the evidence the rest of the list waits on.
- **One call searches more past sessions.** A per-session digest index would reach past the current 20-store, 1.5-second, 40-hit caps. It waits for the summary-quality evidence above, because a second copy of summary text needs invalidation rules and its benefit is unmeasured until then.

## Later

- **Cheaper compaction from deterministic briefs.** A benchmark on our own long transcripts decides whether rule-written briefs replace model-written summaries. The bar is indistinguishable recall at meaningfully lower cost.
- **Cleaner recovery when the window overflows.** Branch back to the last transmissible message, compact, then retry, instead of falling back to the host default. This ships only if overflow frequency matters.
- **DeepSeek support.** A third adapter is planned.

## Out of scope

- **Third-adapter comparisons wait for the adapter.** The two shipping adapters
  each have an audited page, [Pi](/reference/pi/comparison) and
  [OpenCode v2](/reference/opencode/comparison). A harness with no adapter has
  no field to compare.
- **No paper benchmark numbers.** The paper's headline figures come from pieces this build leaves out, so they are not claimed here.
- **No vector recall, no curated memory tier.** Deliberate gaps, with the reasons in the [OpenCode comparison](/reference/opencode/comparison).
- **Secrets mask on exit instead of blocking the write.** Deliberate; same pointer.

Maintainer detail (evidence gates, deferred items, rejected ideas) lives in the repo's [`docs/roadmap.md`](https://github.com/stainless-code/lossless/blob/main/docs/roadmap.md).
