```text
/lcm status
/lcm report
/lcm backup [file]
/lcm export [file]
/lcm import <file>
/lcm gc [--apply]
/lcm migrate [--apply]
/lcm heal [--apply] [--max-nodes N]
/lcm diagnose [--save <file>]
/lcm compact
```

Ten verbs on one `/lcm` command. Subcommand routing is manual dispatch inside the one handler: the command registry rejects a second registration under the same name, so `/lcm report` and friends arrive as raw input.

## Settings

There is no interactive settings panel in scope; the harness exposes no custom-render seam on the composition context, so a settings overlay stays blocked. Edit the capability `config` in the composition and restart it. [Config](/reference/deepseek/config) lists every key.

## status

```text
/lcm status
```

Message and compaction-summary counts for the live sidecars, plus the meter window with thresholds and the last pass outcome for this session. The counts lines stay additive to the older shape.

## report

```text
/lcm report
```

Pass, checkpoint, backfill, recall, and retrieval rows for this session, in the OpenCode vocabulary. It says so when the session has no rows.

## backup

```text
/lcm backup [file]
```

Copies this session's sidecar to `<sidecar>.backup-<timestamp>`, or to the path you name, at mode 0600.

## export

```text
/lcm export [file]
```

Writes the verbatim transcript and summaries as JSONL at mode 0600. The default lands beside the sidecars.

## import

```text
/lcm import <file>
```

Restores rows from a file written by `/lcm export`. Re-importing the same file inserts nothing and reports the skips. Refused without a file argument, or into a store that already holds foreign messages.

## gc

```text
/lcm gc                  # dry-run list
/lcm gc --apply          # export each transcript, then delete
```

Collects sidecars older than 30 days that no live session holds. It never touches a live stem and exports each transcript before deleting it. A no-op apply writes no export file.

## migrate

```text
/lcm migrate             # dry-run list of older-schema sidecars
/lcm migrate --apply     # upgrade them in place
```

Generation-gated: sidecars older than the current schema version are listed, then upgraded in place. Live stems are excluded because a second writer would race the live session.

## heal

```text
/lcm heal                  # dry-run: count the tainted nodes and their ancestors
/lcm heal --apply          # re-summarize them from their stored source
/lcm heal --apply --max-nodes 8
```

A non-clean summary is a candidate. Heal reads the exact source rows that node points at, re-summarizes the tainted node, then recomputes every ancestor whose child changed. `--max-nodes` bounds one run; `summarizerTokensPerHeal` bounds its spend. The dry run makes no provider call. Refused while a compaction pass is in flight, or while a repair already runs for the session.

## diagnose

```text
/lcm diagnose
/lcm diagnose --save <path>      # or --save=<path>
```

One redacted, pasteable block: versions, store facts, the effective options, and this session's metrics. `--save` writes the exact bytes at mode 0600 instead of printing them.

## compact

```text
/lcm compact
```

One manual compaction through the DAG bracket: idle-agent admission, range selection with retain 0, one condensed replace plus log-only leaf records under one compaction id, then the durability flush. Returns null with "No compactable history yet" when no safe useful range exists. Automatic pressure compaction stays on the harness seam unless `bracketAuto` routes it through the bracket too.
