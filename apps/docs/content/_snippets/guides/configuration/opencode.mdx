The OpenCode adapter reads its options from the `plugins` entry in `opencode.json`. It has no separate config file and no interactive settings panel.

```json
{
  "plugins": [
    {
      "package": "opencode-lossless",
      "options": {
        "sidecarDir": "/absolute/path/to/lossless-sidecars",
        "assembly": true,
        "swapAtRatio": 0.7,
        "recutAtRatio": 0.85,
        "keepRecentTokens": 20000,
        "summaryTokens": 1500,
        "summarizerTokensPerCall": 60000,
        "summarizerTokensPerPass": 250000,
        "summarizerTokensPerHeal": 120000,
        "contextWindow": 128000
      }
    }
  ]
}
```

The threshold vocabularies are the same: ratios, `smartZone`, and token pairs. `zones` maps `provider/model` to any of `smartZone`, `swapAtRatio`, `swapAtTokens`, `recutAtRatio`, and `recutAtTokens`. Token thresholds win over `smartZone`, which wins over ratios. The engine clamps the swap ratio to 0.9 and folds a re-cut into `(swap, 0.95]`.

`summarizerTokensPerCall` and `summarizerTokensPerPass` bound a pass. `summarizerTokensPerHeal` bounds an on-demand `/lossless-heal --apply` repair. A malformed value keeps its default.

A heal reads source through windows derived from `summaryTokens` (8x, clamped 3,000 through 24,000 and to `summarizerTokensPerCall`). A leaf that fits one window is sent once. A larger leaf maps up to eight windows and reduces them once. Set `healSourceTokens` to change the window. A source beyond eight windows is blocked with no model call, not retried at the same size. A mechanical node gets one improvement. Raising the window makes the next run attempt it again.

`assembly: false` keeps the mirror and recall tools and leaves compaction to the host. Edit the options and reload the plugin to change them. There is no live settings panel. [Config](/reference/opencode/config) lists every key and default.

To keep sidecars inside the project, set `sidecarDir` to `"./.lossless"`. Without this setting, the plugin stores sidecars in one global directory that holds sessions from every project. The global directory uses `XDG_DATA_HOME` with a `~/.local/share` fallback on Linux and macOS, and `LOCALAPPDATA` with an `APPDATA` fallback and then a `<home>/AppData/Local` fallback on Windows. To use a different location, set `sidecarDir` to a path outside the global directory. [Config](/reference/opencode/config) lists the exact default paths.

To remove old sidecars from the shared directory, run `/lossless-gc`. Orphan sidecars accumulate there because the directory is shared.

After upgrading a project that stored sidecars in `./.lossless`, keep `sidecarDir` set to `"./.lossless"` to keep reading that history. `/lossless-migrate` upgrades sidecars in place in the configured directory only: it is a dry run by default, moves nothing between directories, and cannot recover history left behind in `./.lossless`. To carry history to a new directory, run `/lossless-export` per session under the old config and `/lossless-import` each file into an empty store under the new config, or stop the server first and copy the `.sqlite`, `-wal`, and `-shm` files across and then run `/lossless-migrate --apply`. The plugin never moves sidecars, and the startup warning names both paths.
